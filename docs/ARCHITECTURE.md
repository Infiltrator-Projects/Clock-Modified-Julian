# Modified Julian Date Clock

The provider owns its clock notation and next-tick scheduling. Common 1.19.81 (a99ef676b0e43c7e645c81756e3fd38be0a54406) owns reusable arithmetic and resource APIs. Real Common is built from a pinned Git submodule and linked, never copied into source snapshots. Standalone native installers bundle that precise source and retain regression/accuracy tests.
